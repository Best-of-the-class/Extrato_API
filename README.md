# Extrato_API 🍎

Backend do aplicativo gamificado de educação financeira para crianças a partir de 11 anos.

## 🚀 Tecnologias
* **Linguagem/Framework:** .NET (C#)
* **Banco de Dados:** PostgreSQL
* **ORM:** Entity Framework Core

## ⚙️ Como rodar o projeto
1. Clone este repositório.
2. Abra a solução `Extrato_API.sln` no Visual Studio.
3. Clique no botão de "Play" (Iniciar) no Visual Studio ou pressione `F5`.
